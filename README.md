# CatalogGuard — Shopify CSV Preflight Kit (preview v0.1)

A small independent digital product experiment associated with FeedTripwire. **Not yet for sale.**

## Start
1. Unzip the download.
2. Open `index.html` in a modern browser. No server is required.
3. Click **Try sample issues** to see an example or choose a Shopify **product** CSV file under 10 MB.
4. Review warnings before any import. Download a findings CSV.

## Included
- Local/offline preflight checker (`index.html`, `checker.js`).
- Safe and risky sample product CSV files.
- Short operational checklist (`PRE_IMPORT_CHECKLIST.md`).
- Sample supplier escalation messages (`SUPPLIER_MESSAGES.md`).

## What the tool cannot do
It does not connect to Shopify, validate every CSV rule, guarantee compatibility, edit your source file, or undo any store changes. It checks product CSVs, not Shopify location inventory CSVs. It will flag potential issues that can be intentional for particular stores. **Keep backups and run a small test import.**

**Version:** experimental v0.1. Not affiliated with Shopify.
